# 작업 데이터 보존과 재현성

추론 결과는 job ID와 입력 meta에 묶여 재현돼야 한다. Pi의 `/tmp` meta는 임시 전달 파일일 뿐, 학습·품질 분석의 유일한 근거가 될 수 없다.

- 완료된 job의 NAS 아카이브에는 원본 영상, `meta.json`, 분석 결과, body 결과와 manifest가 함께 있어야 한다.
- 결과 JSON의 `analysisVersion`과 모델/HEF 식별자는 manifest 또는 결과에 기록해, 나중에 같은 입력으로 비교 가능하게 한다.
- `/tmp` 메타가 사라진 경우 백엔드가 NAS 아카이브에서 영속 meta로 복구한다. infer는 복구된 파일을 일반 입력과 동일하게 처리한다.
- HEF 성능 판단은 아카이브된 고정 평가 job과 새로 라벨된 학습 데이터를 분리해 수행한다.

2026-07-25 job `6b9a0b45-03fd-4d18-a194-338e660a05a7`은 `/tmp` 손실에도 NAS에 완전 보관된 복구 사례다. 이 보존 문제는 클럽 핸들/그립의 일반화 실패와는 별도다.
