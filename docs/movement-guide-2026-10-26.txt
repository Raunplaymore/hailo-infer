머리·골반 화면상 움직임 가이드 v1 — 구현/후보 검증 완료, 운영 미배포

범위
- 목표: 사용자가 임팩트 주변의 머리·골반 움직임을 직접 확인하도록 시작 기준과 확인할 장면 제공.
- 코 위치를 머리의 관측점으로, 양쪽 hip 평균을 골반 중심으로 사용. 엉덩이 윤곽/실제 회전 깊이가 아님.
- 화면상의 2D 이동만 표시. 얼리 익스텐션, 머리 고정 성공, 구질/교정 효과 판정 없음.
- 기존 상체 기울기 비교는 접힌 선택 항목으로 유지. 경량 영상과 기존 임팩트 계약 유지.

데이터/계산
- 기존 body JSON의 observed 관측만 사용. 보간/출처 불명 프레임은 제외.
- 관절 confidence>=.75, 화면 내부, 유한 좌표를 요구. 골반은 양쪽 모두 필요.
- ±65ms 최소3표본, 최근접40ms, 표본간 최대70ms. 창 안의 흔들림이 영상높이2%를 넘으면 제외.
- 시작 기준은 초기 요청시점 가까운 안정 구간에서 선택. 머리/골반은 독립적으로 보류.
- 임팩트 후보 전500ms~후200ms에서 머리는 평면 이동량, 골반은 화면 가로 이동량이 가장 큰 관측 선택.
- 후보 주변6표본 이상, 전350ms~후80ms 포함,100ms 이상 공백 없는 조건. 방향의 공 쪽/반대 쪽 해석 안 함.
- 임팩트 후보±40ms는 근처로 표시. 이 시점 자체가 모델 후보임을 유지.
- 영상 표시 시 최근접 관측50ms 밖은 현재 점 숨김. 최근500ms 궤적은100ms 이상 공백을 잇지 않음.
- backend는 클라이언트 impact 시점을 무시하고 검증된 영상hash의 저장 후보만 infer에 전달.
- 기존 preview 응답에 movementGuide 추가. 기존 코칭 확인 절차/라벨/원본 데이터 수정 없음.

검증
- Python synthetic: confidence/결측/보간/중복시각/시간범위/미러링/트랙별독립보류 통과.
- Pi 실제6개: head/pelvis 모두 가이드 생성 가능, 약2.2~6.5ms. 정확한 동작/진단 정답 검증은 아님.
- Pi 후보 기존6개 필수 추론검사 및 새 movement/practice 검사/compileall 통과.
- 후보 HTTP preview 가이드 응답, 미확인review 거부 및 기존 API 계약 통과.
- frontend 계약/결측렌더링/phase 버튼/원본코칭 회귀/typecheck/build 통과.
- backend 전체check 통과. client가 보낸impact 무시 검사 포함.
- 브라우저: 실제 저장 IMG_5741 영상 + Pi 응답 재현으로 골반 기준선, 머리 기준점, 자동 이동장면과 전후 버튼 확인.

제한/배포
- 카메라 고정은 자동 검증하지 않음. 화면/카메라 이동도 관측 이동에 섞임.
- 코의 이동에는 얼굴 회전도 포함. 골반 중심의 이동은 엉덩이깊이/3D회전의 대체 측정이 아님.
- 프로 비교/이전 스윙 자동 비교/신체 교정 처방은 이번 범위에 추가하지 않음.
- 운영은 practice-ux-20261026-r1 상태. 이번 가이드는 아직 운영배포/커밋/푸시하지 않음.
- 적용 시 infer(schema+practice+movement), backend(server), frontend(dist) 순서. 기존release 및 infer파일 백업 후 전환.
